# ui-slint [EXPERIMENTAL]

[EXPERIMENTAL] Evaluation-only Slint UI surface for rust-daq.

This crate is used for prototyping and performance/workflow evaluation.
It is **not** the primary supported operator UI and does not provide full parity with `crates/ui`.

- Primary operator UI: `crates/ui` (egui, native + WASM)
- Auxiliary specialized workflow: `daq-rerun` in `crates/ui`
