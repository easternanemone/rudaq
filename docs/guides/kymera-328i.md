# Kymera 328i Spectrograph Guide

## Overview

Czerny-Turner spectrograph with 328mm focal length.

## Key Specs

| Parameter | Value |
|-----------|-------|
| Focal Length | 328 mm |
| Grating Turret | 3-position |
| Slit Range | 10-2500 um |

## Serial Commands

| Command | Description |
|---------|-------------|
| ?GRATING | Query grating |
| GRATING n | Set grating |
| ?NM | Query wavelength |
| NM xxxx.xx | Go to wavelength |
| ESLIT n | Set entrance slit (um) |
